# Contributing to Project X

We welcome clinical module updates and storefront frontend performance optimizations from fellow medicos and developers!

## Ground Rules
1. [cite_start]**No CSS Inventions:** Do not add raw classes to module sub-files[cite: 217]. [cite_start]Use external templates (`wbuhs_master_style.css`)[cite: 216].
2. [cite_start]**Pedagogical Accuracy:** Any additions to modules must align directly with the WBUHS 15-Year PYQ frequency map[cite: 209, 210].
3. [cite_start]**Validation Loop:** Ensure all files clear automated formatting (`npx prettier --write`) before opening a Pull Request[cite: 303].
